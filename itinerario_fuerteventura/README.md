# Itinerario Fuerteventura 2026

## Struttura Applicazione

```
itinerario_fuerteventura/
├── itinerario.html              # Pagina principale itinerario viaggio
├── style_itinerario.css         # Tema chiaro - design responsive
├── style_itinerario_dark.css    # Tema scuro - modalità notte
├── script_itinerario.js         # Logica interattiva (search, filter, dark mode)
├── image.png                    # Asset visivi
└── prompt_itinerario_fuerte.md  # Documentazione originale
```

## Funzionalità

- **Timeline interattiva**: 8 giorni di viaggio (11-18 Agosto 2026)
- **Filtro per giorno**: Navigazione rapida tra giornate
- **Ricerca**: Cerca luoghi, attività, ristoranti
- **Dark mode**: Toggle tema chiaro/scuro con persistenza
- **Link Maps**: Integrazione Google Maps per ogni location
- **Mobile-first**: Zoom disabilitato, ottimizzato touch
